м# ⚡ Playerok Bot — десктопное приложение

Отдельное приложение для Windows 11: мониторинг заказов Playerok в красивом
минималистичном окне. Без cmd, без консоли.

## ✨ Возможности

- 🪟 **Отдельное окно приложения** — свой тайтлбар, никакой консоли
- 🎨 **6 тем оформления** — Ночь, День, Океан, Фиалка, Закат, Лес.
  Переключение в Настройках, палитра с предпросмотром, плавная смена цветов
- 🔑 **Вход через отдельное окно Playerok** — сайт открывается в обычном окне
  Chromium внутри приложения, входишь как всегда. Никаких cookie руками,
  никаких собственных запросов к API: приложение читает ответы, которые сайт
  сам получает от своего API (через DevTools-протокол).
- 🛒 **Мониторинг заказов** — проверка каждые 15/30/60 сек, уведомления
  Windows о новых оплаченных заказах, бейдж на вкладке
- 🌊 **Плавные анимации** — появление карточек, тосты, смена темы

## 🔧 Как приложение получает заказы

Раньше приложение само слало запросы в `playerok.com/graphql` и получало
`Something went wrong` (HTTP 500): Playerok принимает только «родные» запросы
сайта (persisted queries), подделать их снаружи не получается.

Теперь запросы делает **сам сайт** в окне Playerok (`src/main/siteBrowser.js`):

- `viewer` → профиль; заказ в Playerok живёт внутри чата, поэтому приложение ищет
  заказы (объекты `Deal`/`ItemDeal`) в **любом** ответе сайта — в списке чатов,
  в самом чате, в сообщениях — и копит их;
- обновление: тот же запрос повторяется изнутри страницы (те же cookie,
  заголовки, отпечаток браузера), если не вышло — страница сделок
  перезагружается;
- окно скрыто и показывается только когда нужен человек: войти в аккаунт или
  **один раз** открыть «Чаты» и зайти в чат с заказом (адрес страницы запоминается);
- **что купили и за сколько**: в списке чатов Playerok присылает только id товара,
  поэтому для заказов без названия/суммы приложение тихо открывает чат с заказом в
  скрытом окне, запоминает запрос сайта с подробностями и дальше просто повторяет его
  для других заказов. Результат кэшируется в `deal-details.json`;
- крестик на окне Playerok не закрывает его, а прячет;
- ответы сайта читаются двумя независимыми способами (DevTools-протокол и
  скрипт внутри страницы, `sitePreload.js`) — если один не сработает, работает другой.

`npm start` сам переключает консоль на UTF-8 (`chcp 65001`), чтобы русские сообщения не превращались в «кракозябры».

Если кнопка «Ожидание…» висит — нажми на неё ещё раз, это отмена. Окно Playerok
открывается поверх приложения; если на сайте появилась проверка «я не робот» —
пройди её, затем войди.

Для диагностики: `site.log` в папке данных приложения (что открывалось, какие ошибки
загрузки, какие операции видел сайт), в консоли печатается каждая операция сайта и её HTTP-статус,
а в папке данных приложения (`%APPDATA%\playerok-desktop`) лежит
`last-deals.json` — какие заказы нашлись (там реальные данные!) и `ops-shape.json` —
только структура ответов сайта, без значений.

## 🚀 Запуск (Windows 11)

1. Установи **Node.js 18+** → https://nodejs.org (кнопка LTS)
2. Распакуй архив, открой папку в терминале
   (адресная строка проводника → введи `cmd` → Enter)
3. Установи Electron (один раз, нужен интернет):
   ```powershell
   npm install
   ```
4. Запусти приложение:
   ```powershell
   npm start
   ```

## 🔑 Первый запуск

1. Открой **Настройки** (⚙️ слева)
2. Нажми **«Войти через окно»** → войди в аккаунт Playerok → окно закроется само
3. Выбери тему из палитры 🎨
4. Вернись на **Заказы** → нажми **▶ Запустить**. В первый раз откроется окно
   Playerok — открой «Чаты» и зайди в чат с заказом,
   окно закроется само

Всё — новые оплаченные заказы будут появляться с анимацией и уведомлением.

## 🐾 Автовыдача Adopt Me

Вкладка **«Автовыдача»**. Бот не лезет в Roblox: он смотрит на экран и кликает
мышью как человек (`trader/trader.py`).

**Установка (один раз):**
1. Python 3.10+ с https://python.org (при установке галочка **Add Python to PATH**)
2. В папке проекта: `pip install -r trader/requirements.txt`

**Питомцы:** в рюкзаке игры нажми Win+Shift+S, выдели ячейку с питомцем, затем в
приложении «Вставить картинку». Заполни поля:
- *Поиск*: что бот вводит в поиск рюкзака;
- *Слова из названия товара*: по ним заказ с Playerok связывается с питомцем
  (например `chameleon, хамелеон`);
- *Штук за заказ*.

**Как проходит выдача:** запрос на трейд от покупателя (ник сверяется, чужие
запросы отклоняются) → «+» → поиск → клик по питомцу → проверка, что в трейде
ровно нужное число предметов → Accept (когда кнопка станет зелёной) → проверка на
экране «Is this trade fair?» → Confirm. Если что-то пошло не так, бот
останавливается и присылает уведомление.

**Аварийная остановка:** резко уведи мышь в левый верхний угол экрана, либо кнопка «⛔ Стоп».

Покупатель должен знать твой ник, поэтому укажи его в описании товара на Playerok.
Автосообщение в чат и отметка «Товар отправлен» пока не сделаны.
